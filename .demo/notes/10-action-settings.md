Actions need settings too, and we're adding three here: email, company name and source.

What you might notice is that two of these fields have a new attribute on them: `SupportsBindings`. This is what makes a field dynamic, and lets an editor pipe in values from earlier steps in the automation. We'll get to what that looks like for an editor in a minute.

And for contrast, one field without it — `Source` — which just stays a fixed value every editor types by hand, the same on every run. Every entry from this action comes via the website.

Two fields, one flag apart, and that's the entire difference between a static setting and a dynamic one.
